A Node program that writes the funniest final text a dying phone sends at one percent battery: a 108-character line in the phone's own voice, spending its last breath snitching on its owner and complaining it still gets blamed for dying.

## Run it

```sh
node main.ts
```

It writes the text to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when unset).

## The line

> 1%. Last words: his passcode is 0000, his search history is a crime scene, and he still blames me for dying.

One joke, one voice: the phone opens at 1%, announces its last words, betrays its owner with two specific details, and ends on the complaint that it is the one being blamed. No low-battery pun, no wasted words.
